## Architecture

Single-page conference site for the first Uzbekistan international sleep medicine and apnology conference (28–29.11.2026, Toshkent). All content is in Uzbek.

**Stack:** React 19 + TypeScript, TanStack Router (file-based), TanStack Start (SSR), Vite 7, Tailwind CSS v4, Radix UI / shadcn-ui. Deployed as a static pre-rendered site on Vercel.

**Page structure:** The single route `src/routes/index.tsx` composes all sections in order: `Header → Hero → Program → Speakers → Register → Sponsors → Footer`. Each section lives in `src/components/summit/`.

**Routing:** `src/routeTree.gen.ts` is auto-generated by TanStack Router — never edit it manually. Add new routes by creating files under `src/routes/`.

**UI components:** `src/components/ui/` contains the shadcn/ui library. Prefer these primitives when building new UI. Don't modify them directly.

## Design System

Tailwind v4 is configured entirely via `src/styles.css` — there is no `tailwind.config.js`. All design tokens are CSS custom properties.

- All colors **must** use `oklch` format.
- To add a new semantic color: add the variable to `:root` (light) and `.dark` in `src/styles.css`, then register it in the `@theme inline` block as `--color-<name>: var(--<name>)`.
- Fonts: `font-display` → Space Grotesk (headings), `font-sans` → Inter (body).
- Brand primary: Silent Sleep deep blue `oklch(0.45 0.31 264)`.
- Custom utility classes defined in `src/styles.css`: `grid-pattern`, `shadow-elegant`, `shadow-glow`, `shadow-soft`, `animate-float`.

## Vite Config Constraint

`vite.config.ts` uses `@lovable.dev/vite-tanstack-config`, which already bundles these plugins — **do not add them manually** or the build will break with duplicate plugin errors:

> `tanstackStart`, `viteReact`, `tailwindcss`, `tsConfigPaths`, `cloudflare`, `componentTagger`, `VITE_*` env injection, `@` path alias, React/TanStack dedupe.

Pass any extra Vite config via `defineConfig({ vite: { ... } })`.

## Deployment

Deploys to Vercel as a **static site** — there is no server at runtime.

`npm run build` runs `vite build`, then `scripts/prerender.mjs` boots the built TanStack Start server in-process, fetches `/`, and writes the resulting SSR HTML to `dist/client/index.html`. `vercel.json` serves `dist/client` and rewrites all paths to `/index.html` so client-side routing survives a hard refresh.

Because the page is pre-rendered at build time, **any content change requires a rebuild to appear** — including anything in the `<head>` from `src/routes/__root.tsx`.

The Cloudflare Workers adapter is disabled (`cloudflare: false` in `vite.config.ts`). `wrangler.jsonc` is a leftover from that setup and is not used.
